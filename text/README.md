# 제노코미 SCEN 대사 편집

`SCEN00.txt`~`SCEN06.txt`에서 **`[KOR]`와 `[END]` 사이만** 수정하고, 저장소 루트의 `Rebuild.bat`를 실행한다. `[KOR]`가 비어 있으면 원문 그대로 나온다. `[JPN]`, 주소 ID, 파일 머리말과 구획 표시는 건드리지 않는다. 제어 코드는 임의로 바꾸지 않으며, 개행에 따른 스타일 코드 처리는 아래를 따른다.

## 줄바꿈 바꾸기

일반 대사(`/ MESSAGE`)에서는 **본문에 실제로 Enter를 넣으면 줄이 늘고, 그 줄바꿈을 지우면 줄이 줄어든다.** 문자 두 개로 된 `\n`은 입력하지 않는다. 편집기의 자동 줄바꿈은 게임에 반영되지 않는다.

**1줄 → 2줄.** `SCEN00.txt`의 `[0000008F]`처럼 본문이 한 줄이면, 의미가 끊기는 지점에서 Enter를 넣는다. 변경 후 둘째 줄 앞의 `　`는 여는 낫표 아래를 비워 주는 전각 공백 한 칸이다. 줄바꿈에 꼭 필요한 문자는 아니다.

변경 전:

```text
[KOR]
{0B}{03:01}{0C}시온{0D}
{03:00}「어때, KOS-MOS?」{09}{0B}
[END]
```

변경 후:

```text
[KOR]
{0B}{03:01}{0C}시온{0D}
{03:00}「어때,
　KOS-MOS?」{09}{0B}
[END]
```

**2줄 → 1줄.** `SCEN00.txt`의 `[00000286]`처럼 본문이 두 줄이면, 본문 안의 줄바꿈과 둘째 줄 맨 앞의 들여쓰기를 지운다. 이어 붙인 자리에 띄어쓰기가 필요하면 반각 공백 하나를 넣는다.

변경 전:

```text
[KOR]
{0B}{03:01}{0C}케이오스{0D}
{03:00}「아니, 장 좀 보러 가려고.
　뭐 필요한 거 있어?」{09}{0B}
[END]
```

변경 후:

```text
[KOR]
{0B}{03:01}{0C}케이오스{0D}
{03:00}「아니, 장 좀 보러 가려고. 뭐 필요한 거 있어?」{09}{0B}
[END]
```

- 화자 이름 뒤의 `{0D}` **다음 줄바꿈은 그대로 둔다.** 위의 두 예시에서 늘리거나 줄이는 건 이름 줄이 아닌 본문이다. 본문 끝의 `{09}{0B}`도 마지막 글 뒤에 그대로 둔다.
- `없어진 것`, `할 수 있다`처럼 한 덩어리로 읽히는 표현은 되도록 갈라 놓지 않는다. 한 줄로 합친 결과가 행폭을 넘으면 두 줄을 유지한다.
- **생각 대사:** 각 줄은 기본 스타일로 초기화되므로 `{03:03}`을 각 본문 줄 앞에 넣어야 한다. 한 줄을 두 줄로 늘리면 새 줄에도 `{03:03}`을 넣고, 두 줄을 한 줄로 합치면 이어 붙인 자리의 같은 스타일 코드는 제거한다. 다른 값의 스타일 코드나 대기·화자 제어 코드는 그대로 보존한다. 리빌더는 반복 횟수 대신 실제 스타일 흐름이 유지되는지 검사한다.
- **선택지(`/ CHOICES`):** 실제 줄바꿈 하나가 선택지 하나를 구분한다. 항목 수와 순서를 유지하고, 긴 선택지는 문구를 줄인다. 한 선택지를 두 줄로 쪼개거나 두 선택지를 한 줄에 붙이지 않는다.

생각 대사 한 줄을 두 줄로 바꾸는 예시:

```text
변경 전:
{03:03}“모모도 걱정되지만 지금은 KOS-MOS가 먼저야!”{09}{0B}

변경 후:
{03:03}“모모도 걱정되지만
{03:03}　지금은 KOS-MOS가 먼저야!”{09}{0B}
```

`{03:03}`을 지워서 빌드 검사를 통과시키면 둘째 줄이 기본 스타일로 바뀐다. 정상적인 반복 코드를 유지하고 리빌더의 스타일 검사 결과를 확인한다.

## 행폭 검사

`Rebuild.bat`는 비어 있지 않은 `[KOR]`를 저장 전에 검사한다. 이름이 있는 대사는 **줄당 512px, 본문 최대 3줄**이고, 그 외 메시지와 선택지는 **줄당 600px**를 검사한다. 이 값은 리빌더 기준이며, 모든 화면에서 실제로 600px까지 보인다는 뜻은 아니다.

한글·전각 문자는 20px, 반각 문자는 16px, 반각 공백은 10px로 센다. 전각 공백 `　`도 20px다. 제어 코드는 폭에 포함되지 않는다. 한도를 넘으면 `SCEN00.DAT [00000286]: ADV line exceeds 512px (...px); adjust the KOR line breaks`처럼 파일명과 ID를 표시하고 중단한다. 자동 줄바꿈은 하지 않는다.

## 제어 코드

아래는 현재 SCEN 7개에서 쓰이는 코드다. 리빌더는 **일반 개행을 제외한 모든 제어 코드의 값·개수·순서**가 원문과 같은지 확인한다. 순서만 맞으면 어디로든 옮겨도 된다는 뜻은 아니다. 효과를 적용하는 글 앞이나 뒤에 붙어 있으므로 원래 역할을 유지한다.

| 표기 | 역할 |
| --- | --- |
| `{0B}` | 메시지 창의 줄 버퍼와 출력 상태를 초기화한다. 대사 시작과 끝에 모두 나올 수 있으니 중복처럼 보여도 그대로 둔다. |
| `{03:00}` | 기본 대사 색상 스타일을 선택한다. |
| `{03:01}` | 화자 이름 등에 쓰이는 색상 스타일을 선택한다. |
| `{03:03}` | 생각 대사 등에 쓰이는 색상 스타일을 선택한다. 다음 줄에 자동으로 이어지지 않으므로 각 본문 줄 앞에서 다시 지정한다. |
| `{0C}` / `{0D}` | 글자마다 기다리지 않는 출력 모드를 켜고 끈다. 보통 `{0C}화자 이름{0D}`로 보이며, 코드 자체가 개행을 넣지는 않는다. |
| `{09}` | 대사 끝에서 입력을 기다린다. 줄만 바꾸고 싶다면 이 코드를 추가하는 대신 Enter를 사용한다. |
| 실제 줄바꿈 | 저장될 때 `0A`가 된다. 대사에서는 다음 줄, 선택지에서는 다음 항목을 뜻한다. |

예를 들어 `{03:01}`에서 `03`은 명령, `01`은 그 명령의 인수다. 콜론 뒤 숫자를 줄 수로 해석하지 않는다. 대사에 실제 중괄호를 표시하려면 `{{` 또는 `}}`로 입력한다.
