## 공백 타일 출력 규칙

2026-11-06부터 **편집 PNG의 배치는 유지하고, 리빌드할 때 이름 속 반각 공백 타일만 건너뛴다.**
예를 들어 `토끼 군`은 `토·끼·군` 3블록으로 출력한다. 번역표의 띄어쓰기나 사전·퍼즐 단어는 바꾸지 않는다.
`야외 활동파`, `백마 탄 왕자`, `사랑의 전도사`, `요리의 달인`, `밤의 제왕`, `과시 소비`에도 같은 규칙을 적용한다.
작은·큰 표시 합계 14곳이며, 줄어든 폭·UV 범위·중심점을 함께 갱신한다. 글자를 다시 그리거나 팔레트를 바꾸지 않는다.

기존 `_KOR.png`를 그대로 두고 루트 `Rebuild.bat`을 실행하면 된다. PNG의 공백 칸을 직접 지우거나 뒤 글자를 옮기지 않는다.
리빌드 후 재추출한 두 팔레트의 비교 결과는 `diagnostic-name-layout/compact-names-check.json`,
비교 그림은 같은 폴더의 `compact-names-preview.png`에 있다. 변경 전 도구는 `before-space-collapse-20261106.zip`에 보관했다.
