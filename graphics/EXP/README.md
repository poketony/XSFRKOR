# EXP 그래픽

**이 폴더의 PNG를 수정해 옆에 `원래이름_KOR.png`로 저장한 뒤, 저장소 루트 `Rebuild.bat`를 실행하면 됩니다.** 결과 `rebuilt/EXP/FILES/...`를 외부 `UNPACKED/EXP/FILES/...`의 같은 경로로 직접 옮깁니다. 원본 PNG와 크기는 유지하세요.

| PNG | 편집 내용 |
| --- | --- |
| `ctrl_*`, `font_character_select`, `obj_*` | 메뉴 글자 39장. 불투명 회색조로 편집하며 원래 팔레트에 맞춰 16단계로 자동 양자화 |
| `ce001_999` ~ `ce017_999` | 맵 이름 17종. 흰색은 표시, 검정은 투명인 회색조 알파 마스크. 배경 효과는 별도로 수정할 필요 없음 |
| `tuto` | 체험판 게임 목적·필드 조작 설명 |
| `mnt_set` | 화면 위치 조정의 버튼 안내 |
| `titlefan` | 체험판 타이틀. **RGBA와 투명도를 유지**하면 PS2 알파 범위로 변환 후 ARX로 재압축 |
| `gameov2` | 체험판 종료 화면의 일본어 포함 로고 |

예: `obj_item_KOR.png` 또는 `tuto_KOR.png`를 두고 같은 BAT를 실행합니다. PSD는 작업용으로 함께 두어도 됩니다. `_KOR.png`가 없거나 픽셀이 원본과 같으면 적용하지 않습니다. `ctrl_button` 한 장은 같은 버튼 글자 네 곳에 함께 반영됩니다.

`tuto`·`mnt_set`·`gameov2`는 불투명 RGB로 편집합니다. 게임 형식이 JPEG이므로 재압축 손실이 있습니다. 원본의 색차 샘플링은 유지하며 품질 95부터 80까지 필요한 범위에서 조정하고, 128KiB 입력 공간을 넘으면 저장을 중단합니다. 그림 크기를 자동 축소하지 않습니다.

메뉴·라벨은 원본 파일 크기·팔레트·UV를 유지합니다. 그래픽만 수정하면 ELF·문자 폰트는 불필요하게 산출하지 않습니다. [대상·검증·보류 범위](../../codex-lab/freaks/EXP-GRAPHICS.md)를 참고하세요.
